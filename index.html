Setup Instructions

  1. Install ADB (Android Debug Bridge):
    • Windows: Download from Android SDK Platform Tools
    • Mac: brew install android-platform-tools
    • Linux: sudo apt install adb
  2. Install scrcpy:
    • Windows: scoop install scrcpy or download from GitHub
    • Mac: brew install scrcpy
    • Linux: sudo apt install scrcpy
  3. Enable USB Debugging on your Android phone:
    • Go to Settings → About Phone
    • Tap "Build Number" 7 times to enable Developer Options
    • Go to Settings → Developer Options
    • Enable "USB Debugging"
  4. Connect your phone via USB cable
  5. Accept the USB debugging prompt on your phone
  6. Click "Refresh Devices" above to detect your phone
